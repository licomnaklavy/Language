# Лангуаге - Образовательная платформа для изучения английского языка

## Описание проекта

Лангуаге - это клиентская часть образовательной платформы для изучения английского языка с элементами геймификации и системой интерактивных достижений пользователя. Проект включает в себя курсы с теоретическими материалами, личный словарь с возможностью управления словами, систему тестирования для проверки знаний, а также отслеживание прогресса и достижений.

Проект выполнен в рамках курсовой работы по дисциплине "Фронтенд-разработка". Все данные хранятся в localStorage, что позволяет имитировать работу с бэкендом без необходимости развертывания серверной части.

## Функциональные возможности

### Курсы
- Два курса по английскому языку: "Введение" и "Времена"
- Теоретические материалы с примерами
- Поурочное изучение с отслеживанием прогресса
- Возможность переключаться между уроками

### Словарь
- Создание и управление несколькими словарями
- Добавление, редактирование и удаление слов
- Импорт слов из текстовых файлов (формат: слово|перевод|пример)
- Поиск слов по словарю

### Тестирование
- Три режима формирования вопросов: строгий (вопросы и варианты из выбранных слов), расширенный (варианты из всех слов выбранных словарей), полный (варианты из всех словарей)
- Два направления перевода: английский -> русский и русский -> английский
- Настраиваемое количество вопросов (5, 10, 15, 20, все слова или своё значение)
- Выбор словарей для тестирования
- Отображение результатов с разбором ошибок
- Досрочное завершение теста со статистикой

### Достижения
- "Первые шаги" - завершить первый урок
- "Любознательный" - добавить 50 слов в словари
- "Полиглот" - создать 2 словаря
- Всплывающие уведомления при получении достижений
- Отображение прогресса по каждому достижению

### Профиль
- Статистика пройденных курсов и уроков
- Статистика по словарям (количество словарей и слов)
- Список достижений с прогрессом

## Технологии

- HTML5
- CSS3 (Flexbox, Grid, медиа-запросы)
- JavaScript (ES6+)
- LocalStorage для эмуляции бэкенда
- Модульная структура с использованием ES-модулей

## Установка и запуск

### Требования
- Любой современный веб-браузер (Chrome, Firefox, Edge, Safari)
- Visual Studio Code (рекомендуется)
- Расширение Live Server для VS Code (рекомендуется)

### Инструкция по запуску

1. Скачайте или склонируйте репозиторий с проектом
2. Откройте папку проекта в Visual Studio Code
3. Установите расширение Live Server (если не установлено)
4. Откройте файл index.html в редакторе
5. Нажмите правой кнопкой мыши на вкладке с файлом и выберите "Open with Live Server"
6. Или нажмите сочетание клавиш Alt+L, затем Alt+O
7. Браузер автоматически откроется с главной страницей приложения

## Тестовые данные

Для проверки работы импорта слов в словарь можно использовать файл со следующим содержимым:

apple|яблоко|I eat an apple every day
cat|кот|My cat is black
dog|собака|The dog is barking
house|дом|My house is big
car|машина|I drive a red car

## Используемые ключи localStorage

| Ключ | Описание |
|------|----------|
| languege_dictionaries | Массив словарей с их словами |
| languege_selected_dicts | Массив ID выбранных для отображения словарей |
| languege_completed_lessons | Объект с прогрессом по урокам |
| languege_unlocked_achievements | Массив ID полученных достижений |
